# 🦷 DentalCare - Clinic Management & Booking System

## 📖 About the Application
DentalCare is a modern, fast, and user-friendly web application built specifically for dental clinics. It bridges the gap between patients and the doctor by providing a seamless online booking experience. 

For patients, the platform offers a beautiful public interface to explore clinic services (like Digital X-Ray, Root Canal, Precision Dentistry), meet the doctor, and book appointments instantly. For the clinic admin (Doctor), it provides a secure, private dashboard to manage daily appointments, track patient history, and monitor clinic statistics in real-time.

---

## 🚀 How to Run the Website (Local Setup)

Follow these simple steps to run this application on your computer:

### Prerequisites
Make sure you have **Node.js** installed on your computer. If not, download it from [nodejs.org](https://nodejs.org/).

### Step 1: Open Terminal
Open your terminal (or VS Code terminal) and navigate to the folder where you have saved this project.

### Step 2: Install Packages (Dependencies)
Before running the app, you need to download all the required packages (like React, Tailwind CSS, React Router). Run the following command:
```bash
npm install
(Note: You can also use npm i as a shortcut. This will read the package.json file and install everything automatically).

Step 3: Start the Application
Once the installation is complete, start the local development server by running:

Bash
npm run dev
Step 4: Open in Browser
After running the above command, Vite will give you a local link in your terminal (usually http://localhost:5173). Click on that link or paste it into your browser to see the live website!

✨ Key Features
👤 For Patients (Public Portal)
Interactive UI: Clean, modern, and mobile-friendly interface built with Tailwind CSS.

Service Overview: Details about the latest clinic facilities and tools.

Quick Contact: One-click functionality to directly open the phone dialer or email app.

👨‍⚕️ For Doctor (Admin Dashboard)
Overview Stats: Dashboard showing total patients, pending/confirmed appointments, and today's schedule.

Appointment Management: Review, accept, or complete patient appointment requests.

Patient Records: Securely add new patients, view medical history, and track upcoming follow-ups.

🛠️ Tech Stack
Frontend Framework: React.js (Vite)

Routing: React Router v6

Styling: Tailwind CSS

State Management: React Context API (AuthContext, PatientContext, AppointmentContext)
